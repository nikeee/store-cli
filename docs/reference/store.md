## store

Manage App Store Connect and Google Play from the command line

### Synopsis

Manage App Store Connect and Google Play from the command line: builds, TestFlight, versions,
listings, screenshots, tracks and releases, for both stores with the same verbs.
Commands are called as: store <apple|google> <noun> <verb> [args] [flags].

```
store [flags]
```

### Options

```
  -h, --help            help for store
  -o, --output string   output format: text, json or toon (default: auto)
  -v, --verbose         log every HTTP request to stderr
```
